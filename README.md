# LAUSD Gifted Middle School Shortlist

This folder contains a single-file, mobile-friendly review page for sharing with family.

## Publish with GitHub Pages

1. Create a new GitHub repository and upload `index.html`.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. GitHub will provide a shareable `github.io` link after the page builds.

The page is static and does not require a build step.
